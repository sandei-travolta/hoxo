# hoxo

A self-hosted personal business management platform for freelancers and indie makers

## Core Features

<b>1. CRM / Clients</b>
* Manage leads
* Keep track of clients
* Client pipeline: Lead-Proposal-Active-Completed

<b>2. Projects</b>
* Projects per client
* Tasks and deadline
* Milestones
* Progress tracking

<b>3. CRM / Clients</b>
* Create quotations
* Convert quote - project
* Convert project/milestone - invoice

<b>4. Invoicing & Payments</b>
* Professional invoices
* Payment status
* Overdue reminders
* Recurring invoices

<b>5. Expenses & Finance</b>
* Record expenses
* Income vs expenses
* Profit per project
* Monthly revenue
* Cash-flow dashboard

<b>5. Time Tracking</b>
* Track hours per project

<b>7. Contracts</b>
* Contract templates
* Client acceptance/signing
* Attach contracts to projects
